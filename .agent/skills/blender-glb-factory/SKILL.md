# Headless Blender .GLB 3D Factory Skill
- Write standalone `bpy` scripts executed via `blender --background --python <script.py>`.
- Export optimized, UV-mapped `.glb` files into `Assets/StreamingAssets/Models/` for `glTFast` streaming.
